Chota Bot Map

What the family bot is made of, where its data lives, and what it could do next. One page to come back to when planning; updated as things ship.

How it fits together

One Node process on the kitchen box (pop-os, moving to a Pi 5). Every chat app goes through one router to one agent; scheduled jobs print and alert on their own.

Solid: built and running.Dashed: planned.

Where the data lives

SQLite · data/home.db

  • chat_message: last 50 messages per thread (tg:…, wa:…), text only
  • alert: open/resolved alerts, so deploys don't resend
  • decision: every Jev verdict with its probabilities, for tuning
  • user, session, account, verification: Google login (better-auth)
  • About 100 KB. Drizzle schema in src/lib/server/db/.

Files · data/

  • logs/: LogTape, rotating 8 MB files (~87 MB on the box)
  • sentral/: timetable .ics + cookie per kid
  • whatsapp-auth/: the WhatsApp login (~900 small files; back up whole)
  • files/<chat>/: photos and voice notes people send

Config & secrets

  • chota.config.ts: family (name, aliases, email, WhatsApp, Telegram id), lists, buses, channels, alerts. The only place real names live.
  • .env: API keys and tokens
  • Both gitignored, copied to the box on deploy. Backup: open question.

Content & memory

  • ../curios/dist: literary-clock quotes (1,431 of 1,440 minutes), puzzles, TV and comic quotes
  • TickTick: the family's shared record of to-dos
  • Planned: a family home folder of markdown (soul, memory, people, projects) the bot reads and edits, synced with git
